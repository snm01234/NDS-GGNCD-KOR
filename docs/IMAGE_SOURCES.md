# 대표 이미지의 출처와 표시 방식

이 문서 묶음은 기존 제작물의 이미지를 복사해 사용합니다. 문서 제작을 위해 새로운 게임 화면이나 그래픽을 생성하지 않았습니다.

| 이미지 | 제작 근거 | 설명 |
|---|---|---|
| `cross-drive-logo.png` | v064 출력 ROM의 로고 리소스 `1ED3`를 역변환한 PNG | 게임 해상도·팔레트로 변환된 적용 결과 |
| `character-ui.png` | v069의 첨부 ds2 상태에 출력 ROM의 제목 타일을 반영한 정적 합성 | 캐릭터·능력 화면과 축소한 한국어 제목 |
| `combination-banner.png` | v063의 첨부 상태에 합동공격명과 배너 타일을 반영한 정적 합성 | 아가마 플래툰 명칭과 합동공격 배너 |
| `save-confirmation-ui.png` | v069 첨부 ds1 상태에 v070의 저장 확인 제목 타일을 반영한 정적 합성 | 목표·유닛 수·플레이 시간·저장 일시 제목 크기 교정 |
| `options-ui.png` | v069 첨부 ds2 상태에 v071의 설정 화면 타일을 반영한 정적 합성 | 해금된 아군 제목 높이와 배경선, 메시지 스킵 끔 등 버튼 교정 |

기존 로고·합동공격 배너·명칭 표 및 v069 캐릭터 제목, v070 저장 확인 제목 리소스가 v071에서도 보존되는지 문서 묶음 제작 시 바이트 단위로 대조했습니다. 설정 화면 이미지는 v071 출력 SHA-256과 정적 재구성 검증 기록을 대조했습니다.

정적 합성은 저장된 VRAM·OAM·팔레트와 레이어 정보를 사용합니다. 이 이미지를 실제 게임 CPU를 새로 실행한 캡처나 모든 플레이 장면의 실행 검증 자료로 해석해서는 안 됩니다.
