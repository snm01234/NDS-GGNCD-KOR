# 1.0.0 릴리스 노트

배포일: 2026-10-24  
제작 기준: 내부 작업본 v071 OPTIONS_ALIGNMENT

배포 버전 **1.0.0**을 유지한 갱신본입니다. 기존 v069 기준 배포본에 v070·v071의 UI 교정을 포함했습니다. 파일 이름은 같고 패치·ZIP·결과 ROM의 해시는 달라지므로 [현재 확인 값](../SHA256SUMS_RELEASE.txt)을 사용해 주세요.

## 이번 갱신 내용

| 항목 | 내용 |
|---|---|
| 저장 확인 화면 | 목표·유닛 수·플레이 시간·저장 일시 제목을 작은 글꼴로 다시 그려 배경 안에 여백 확보 |
| 해금된 아군 전투 애니메이션 | 상단 아군 제목을 페이지 넘김·축척 조정과 같은 높이로 배치하고 아래 배경선 복원 |
| 설정 버튼 | 메시지 스킵 끔을 포함한 켬·끔, 오른손·왼손, 표준·간략의 일반·선택 상태 16개에서 일본어 잔여 획 제거 |
| 원본 스타일 | 설정 버튼 테두리와 일반·선택 색상 유지 |

## 누적 반영 내용

- 시나리오와 전투 대사, 도감 및 이름·용어의 한국어 번역과 교정
- 고유명사·계급 표현과 화자별 형제 호칭 교정
- 말더듬·말줄임표·장음 표현 및 도감의 문장부호 정리
- 합동공격명과 배너, 게임 내 로고 3종의 한글화·교체
- 배지의 배경·글꼴·색상과 메뉴 제목의 배치 교정
- 파츠 포커스가 인접 명칭을 덮는 표시 오류 개선
- 저장 화면의 색적 표기, 도감 작품명의 노란 글자와 장비 정보창 크기 교정
- v069의 메뉴 제목 5개 및 튜토리얼 목록 7개 교정, 내레이션 393개 점검과 7줄 설명 2개의 잘림 교정
- 바톤·스트라이크 루즈 등의 지정 이름과 세이라·아이나의 오빠 호칭 교정

## 배포 및 확인

수정하지 않은 일본판 원본에 적용하는 xdelta 패치입니다. 적용 결과는 v071과 바이트 단위로 같습니다. 원본이나 완성 ROM은 배포 묶음에 포함하지 않습니다.

패치 복원 일치 검사를 통과했습니다. v071의 정적 검사 19개를 통과했으며, v070은 17개, v069는 21개를 각 작업 단계에서 통과했습니다. 이 수치는 단계별 검사이며 합산한 고유 검사 수를 뜻하지 않습니다. 이번 배포 작업에서 게임 CPU나 에뮬레이터 실행 검증은 하지 않았습니다.

새 ROM을 재시작한 뒤 일반 게임 저장을 불러와 확인해 주세요. 자세한 내용은 [적용 안내](INSTALL.md)와 [검증 범위](VERIFICATION.md)를 참고해 주세요.
