# 1.0.0 검증 범위

## 패치 파일 검증

1. 일본판 원본과 v071의 SHA-256을 확인했습니다.
2. 원본에서 v071을 만드는 xdelta 패치를 생성했습니다.
3. 생성한 패치를 원본에 적용해 새 ROM을 만들었습니다.
4. 복원 결과를 v071과 바이트 단위로 비교해 완전 일치를 확인했습니다.
5. 원본과 v071이 수정되지 않았고, ZIP 내용이 배포 파일과 일치함을 확인했습니다.

원본·결과·패치의 확인 값은 [배포 명세](../release_manifest.json)에 있습니다.

## v071 및 v070 정적 검사

최신 v071은 정적 검사 19개를 통과했습니다. v070의 저장 확인 화면 교정은 당시 17개 검사를 통과했으며, v071에서 해당 리소스의 보존을 확인했습니다.

| 범위 | 확인 내용 |
|---|---|
| 파일 구조 | FAT 8,211개, 런타임 카탈로그 8,205개, CRC와 영역 비중첩 |
| v071 수정 리소스 | 상단 설정 화면 1C55 한 개, 원본 타일 315개와 맵 4개 및 팔레트 비트·테두리 보존 |
| 아군 제목 | 페이지 넘김·축척 조정과 같은 화면 y=77~83에 배치, 아래 y=88 구분선 복원 |
| 설정 버튼 | 일반 8개·선택 8개를 전체 영역 재독해 한국어·그림자·배경·테두리와 대조 |
| v070 저장 제목 | 목표·유닛 수·플레이 시간·저장 일시 4개를 검은 띠 안에 위아래 최소 2픽셀 여백으로 배치 |
| 기존 수정 보존 | 문자열, 두 폰트 뱅크의 모든 글리프, 코드·포인터·6개 오버레이 및 이전 UI 리소스 보존 |
| 화면 예시 | 첨부 상태의 타일·팔레트·배치로 정적 재구성, v071 상단 지정 영역 712픽셀만 변경되고 영역 밖·하단 0픽셀 변경 |

아래 v069의 21개 검사는 그 단계에서 수행한 이전 검사입니다. 단계별 검사 수를 합산한 고유 검사 수로 표시하지 않습니다.

## v069 정적 검사

총 21개 검사를 통과했습니다. 주요 확인 사항은 다음과 같습니다.

| 범위 | 확인 내용 |
|---|---|
| 파일 구조 | FAT 8,211개, 런타임 카탈로그 8,205개, CRC와 영역 비중첩 |
| 수정 리소스 | 제목 이미지 2개·튜토리얼 스크립트 3개 외 리소스 보존 |
| 제목 | 5개 문구가 원본 검은 띠 안에 최소 2픽셀 여백을 두고 배치됨 |
| 튜토리얼 | 수정 스크립트 전체의 명령·분기·함수표·다른 문구 보존 |
| 내레이션 | 393개를 재독해 최대 6줄, 줄당 최대 18글리프 및 종료값 확인 |
| 글꼴·이름·기존 수정 | 두 글꼴 은행, 상주 이름과 포인터, 바톤·루즈·호칭 및 기존 UI 교정 보존 |
| 화면 예시 | 첨부 상태의 팔레트·타일·배치를 이용한 정적 재구성으로 수정 영역 확인 |

v068에서는 구조가 확인된 표시 단위 87,269개를 재독해 비교했습니다. 표시 단위는 이름 필드 하나나 설명·대사 묶음 하나를 뜻하므로 번역 문장 수와 같지 않습니다. v069에서는 수정 스크립트의 표시 단위를 다시 읽고, 그 외 단위는 리소스와 상주 데이터의 바이트 동일성으로 보존을 확인했습니다. v070과 v071은 문자열을 수정하지 않았으며, 이 문자열 데이터의 바이트 동일성을 확인했습니다.

## 실제 플레이 검증과의 구분

위 내용은 데이터와 화면 배치에 대한 검사입니다. 자동 제작·검증 과정에서는 게임 CPU나 에뮬레이터를 실행한 검증을 하지 않았습니다. 대표 이미지는 기존 저장 상태를 바탕으로 만든 정적 재구성입니다.

게임의 모든 분기·조건과 기기·에뮬레이터별 호환성, 실제 실행 중 메모리 수명까지 검증을 마친 상태는 아닙니다. 구조를 아직 해석하지 못한 데이터나 특정 조건의 화면에서 미번역·표시 오류가 추가로 발견될 수 있습니다. 플레이 제보를 바탕으로 후속 교정을 진행할 수 있습니다.
